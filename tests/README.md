# План тестирования

Это план, а не набор уже выполненных автоматических тестов. В исходном проекте тестов и npm test не обнаружено. Команда npm run verify выполняет проверку типов, линтер и сборку.

Приоритеты семестра:

1. Сохранение профилей: секреты не возвращаются рендереру, изменение имени не теряет сохранённый пароль, ошибки файла не приводят к незаметной потере данных.
2. SSH: вход по паролю и ключу, неверные данные, разрыв соединения, доверие новому ключу и отказ при его изменении.
3. SFTP: листинг, upload/download с побайтовой сверкой, отказ доступа, отсутствие shell при работающем SFTP.
4. Локальный PTY: ввод/вывод, изменение размера, закрытие и кириллица.
5. Интерфейс: независимые панели, переключение и закрытие вкладок, смена каталога после переподключения.

Ручной сценарий первого запуска находится в README. Идентификаторы T-n вводятся начиная с лабораторной № 2 вместе с требованиями.
