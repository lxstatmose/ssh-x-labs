## Наблюдение 1

**Заголовок:** Согласовать точные версии Node.js для локального запуска и CI

**Метка:** question

**Текст:**

Исходный .nvmrc содержит 20 без точной версии, package.json допускает Node.js >=20, CI проверяет 20/22. Современные Vite и ESLint предъявляют требования к минимальным минорным версиям среды. Локально установка и verify пройдены на Node.js 26.12.0, npm 11.20.0; .nvmrc лабораторной фиксирует 26.12.0. Совместимость с исходной CI-матрицей не подтверждена.

Критерий закрытия: согласованы поддерживаемые точные версии, локальная инструкция и CI им соответствуют, npm ci и verify пройдены на выбранных версиях. В исходниках lock-файл уже был; версия корневого пакета в нём актуализирована с 1.0.0 до 1.0.1, дерево зависимостей сохранено.

Критерий закрытия: согласован план, выбран способ запуска тестов и добавлены первые поведенческие проверки с документацией. План находится в tests/README.md.

## Наблюдение 3

**Заголовок:** Проверить зависимости React Hooks в терминале и файловых менеджерах

**Метка:** question

**Текст:**

npm run lint на изученном исходном коде сообщает 8 предупреждений react-hooks/exhaustive-deps: FtpExplorer.tsx — 2, SftpExplorer.tsx — 2, SessionTab.tsx — 4. Проверка завершается без ошибок, но зависимости эффектов требуют анализа.

Проверить смену удалённого каталога, переподключение, переключение активной вкладки и изменение размеров. Предупреждение само по себе не доказывает пользовательский дефект: нельзя механически добавлять зависимости и создавать циклы эффектов.

Критерий закрытия: предупреждения устранены с проверкой поведения либо для сознательно стабильных эффектов документировано обоснование. Фактический вывод — evidence/verify.log.
